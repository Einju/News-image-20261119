A Python program that draws a 1024x1024 HD infographic poster summing up Thursday 19 November 2026's world news: the Trump-Xi-Putin summit in Shenzhen, Anthropic's Nasdaq debut, the widening Gulf war, the GTA VI global launch, the EU's 45 billion euro Ukraine loan, and Cyclone Akvan near India. Pure standard library, deterministic: it renders at 2048x2048 and downsamples to 1024x1024, and every run writes the same PNG bytes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
